## 维护规则

1. 更新前执行 `git pull --ff-only`，以仓库最新目录为准。
2. 新图片必须登记来源页、版权标记、实际文件尺寸和 SHA-256。存疑条目先放入 `assets/review/`。
3. 对照所有历史分组检查馆藏编号、作品身份、哈希和不同裁切/色调版本。不能只比较标题。
4. 排期图片使用仓库相对路径；运行发布工具前由本地程序解析为绝对路径。
5. 平台返回成功后再更新状态；保存计划不能标成已经提交或已经发布。
6. 执行完整性验证，再提交并推送。不得上传 Cookie、令牌、登录二维码、账号凭据或本地发布服务日志。

此库记录本项目实际收集到的资源，不代表全球莫奈作品或全球可下载图像的全集。
